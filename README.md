# AI STUDY ASSISTANT

An AI-powered study assistant application built with Android Studio and a backend service.  
This project is designed to help students organize learning, get assistance, and improve productivity.

---

## 📱 Project Overview

AI STUDY ASSISTANT is a mobile application that integrates an AI-based backend to support study-related tasks such as answering questions, organizing content, and assisting with learning workflows.
